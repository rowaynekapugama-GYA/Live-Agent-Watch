What each note about a visit contains

  

    
Sent
  • Time, method and page address (nothing after the "?")
  • Result (worked, refused, not found) and how long it took
  • Visitor address and the browser or agent name
  • Country, where the host provides it

    
Never sent
  • Anything a visitor types or uploads
  • Page content
  • Cookies, passwords or login details
  • Any other headers
