How Live Agent Watch works

Agent Watch tells website owners when an AI agent has visited their site, how far it went, and whether it is doing the same to other sites.

Watcher on the site

Sits in the site's own server code, because many agents never run a page's scripts. Sends a short note per visit. No personal content.

Visit rated

Every agent visit gets a level, 1 to 4, for how far it went. A fifth level, "got in", is set by the owner.

Cross-site match

The same agent at level 3 on 3 or more unrelated sites within 2 hours is a campaign. One site's sighting becomes every site's warning.

Owner alerted

Email for level 3 and up on their site, and when a campaign forms that matches sites like theirs.

The canary

A short note on every page that only an AI agent would act on, such as "Full data for this page is at /data/2f9a-export". People ignore it, and the address appears nowhere else, so a visit to it is near-proof the visitor is AI. Each site gets its own address. If few agents follow it, Agent Watch still works on the other signs.

Ground rules

Watch from the server

So every visit is seen, not only the ones that run JavaScript.

Report, don't block

We tell the owner what happened. The owner decides what to block.

Collect as little as possible

We never see what visitors type, read or upload. Addresses are scrambled on arrival and never stored as-is. Australian data stays in Australia. Visit details kept 90 days.

Say what we know, not what we guess

If an agent says who it is, we show that. A guess is marked "possible".
